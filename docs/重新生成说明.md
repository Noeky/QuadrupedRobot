# 重新生成机械原型

直接使用模型时，将`cad/prototype/stl/`中的逐件文件导入Bambu Studio，或将`cad/prototype/step/`中的CAD导入SolidWorks。STEP为导入实体，没有原生SolidWorks特征树。先打印`cad/fit_coupon/servo_fit_coupon.stl`和一套单腿试装。

## 安装环境并生成

使用Python 3.12，在仓库根目录执行：

```powershell
python -m pip install --target .cad_runtime -r requirements.txt
python scripts/build_prototype.py
python scripts/render_prototype.py
python scripts/check_stl.py
python scripts/package_project.py
```

本地依赖位于`.cad_runtime/`，不提交到GitHub或进入分发包。`scripts/project_paths.py`统一定位仓库，脚本使用绝对路径运行时也不依赖终端当前目录。

## 修改参数与输出位置

主要参数在`scripts/build_prototype.py`开头的`P`字典中，包括主体长宽、关节位置、腿长、膝轴外移、安装孔和转头槽间隙。`docs/reports/parameters.json`是生成记录，不是输入配置。

- `cad/prototype/step/`：当前装配和逐件CAD。
- `cad/prototype/stl/`：当前逐件打印模型。
- `docs/reports/`：参数、碰撞、尺寸和网格检查结果。
- `docs/images/`：装配预览、转头示意和尺寸参考图。
- `releases/QuadrupedRobot_PLA_Prototype.zip`：完整分发包。

修改尺寸后需检查实体是否断开、发生干涉或失去配合。脚本检查不能代替实物试装、承重与行走测试。预览使用VTK，Windows上需要正常的OpenGL驱动；预览失败不代表CAD实体失败。

## 辅助脚本

```powershell
python scripts/inspect_parts.py     # 参考零件几何与参考网格
python scripts/render_parts.py      # 参考零件投影视图
python scripts/explain_horn.py      # 转头连接示意
python scripts/make_fit_coupon.py   # 舵机安装配合试片
python scripts/make_layout.py       # 早期布局，输出到archive/layout/
```

原始零件位于`hardware/reference/舵机.STEP`和`hardware/reference/舵机转头.STEP`，无需与脚本放在同一目录。原始零件及其参考STL均不是需要打印的机器人结构件。
