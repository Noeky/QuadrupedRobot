# R3 装配五金与工具（2026-10-29）

按当前 SolidWorks 零件、每腿两舵机、共四腿，以及主板固定框和超声波立板统计。螺钉数量由连接点确定；长度按 CAD 厚度、普通六角螺母和薄平垫估算，紧固件实体尚未纳入干涉检查，复刻样机时可先装一条腿核对叠层厚度。第 13 周样机已完成整机装配和带载行走。

## 工具

- 精密十字螺丝刀套装，覆盖PH00、PH0、PH1；实际按螺钉十字槽选择贴合的一支。
- 4mm和5.5mm小扳手/套筒，分别夹持普通M2、M3六角螺母；尖嘴钳可辅助狭窄位置，但不要夹坏螺纹。
- 尖嘴钳或镊子、小斜口钳：拿取螺母、去支撑及剪扎带。
- 小锉刀或去毛刺刀：修掉孔口、配合面残余支撑。
- 卡尺：确认厚度、孔径及螺钉长度。若孔确有残丝，可备手捻钻和小钻头轻清理打印孔；不要直接用电钻扩PCB孔。
- 舵机置中手段：能输出中位PWM的现有主板程序，或独立舵机测试器，二选一。先空载置中再断电装舵臂，不靠手掰齿轮找中位。

主板已完成焊接，本轮机械装配不必为此另购焊台、丝锥或热熔螺母设备。

## 试装顺序与长度确认

1. 先拿一颗M2螺钉试穿实际舵机耳孔和超声波孔，确认能自然通过；这些孔之前并未完成螺钉实试。
2. 先装一条腿。确认髋、膝压板真正压住舵臂，不能仅靠拧紧力把不合适的槽拉到位。
3. 对照实际叠层检查螺钉长度：髋压板约9.85+2mm，膝压板约5.5+2mm，舵机安装框约2.5mm加实际安装耳厚度；再加平垫和螺母。
4. 螺母完整旋合后，末端宜只多露少量螺纹。手动低负载检查关节，确认螺钉头、螺母和末端不碰舵机壳体。
5. PCB本身Ø2.4mm孔使用M2。模型中舵臂的Ø3mm中央通孔是让位孔，**不能据此购买M3中心螺钉**；输出轴螺纹/自攻规格必须匹配原装件，缺件时携原螺钉或实际舵机配样。

普通螺母尺寸参考：[Westfield Fasteners 公制六角螺母尺寸表](https://www.westfieldfasteners.co.uk/Standards/Nut_Hex_M.html)。最终应以买到的螺母、垫片和螺钉实物尺寸为准。
