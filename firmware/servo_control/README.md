# 八舵机控制与基础前行

Arduino IDE打开本目录`servo_control.ino`，同目录保留全部头文件。依赖ESP32开发板包和ESP32Servo库。接线以[引脚分配](../../hardware/引脚分配.md)为准，左右均按机器人自身判断，超声波支架端为前方。

## 当前步态

四拍爬行顺序：**左前→右后→右前→左后**。周期4秒，每腿摆动占20%、支撑占80%，不同时抬两条腿。步长28mm，抬脚12mm；摆动阶段前25%原地抬脚收膝、中50%保持收腿向前迈、后25%在前方伸腿落脚。支撑脚向后移动。

采用40/45mm两连杆逆解，参考脚位置为髋轴正下方65mm（x向前，z向下）。参考几何角为髋前摆43.049°、膝后弯80.406°，它们不是可直接发送给舵机的命令角。每20ms更新，通过已标定的站姿角和方向映射到servo.write()。开始运动和回站姿用1.5秒插值。

## 启动与校准

50Hz PWM、attach(pin,500,2500)，开机依次执行90°，再读取已保存的标定。**90°是电气中位，既不代表机械零位，也不保证是站姿。**读取标定不会自动回站姿或行走。500～2500μs是此前试验使用的范围，不表示各只舵机都恰好转180°；命令只校验0～180输入域，没有额外机械限位。

首次运行托起机身，逐路用小角度变化检查方向和干涉：

1. 用`编号 角度`调整站姿，使脚位于髋轴正下方约65mm、各腿采用小腿后弯的同一逆解分支。用`capture`记录八路最后命令角度。
2. 用`dir 编号 1`或`dir 编号 -1`逐路设方向。髋：命令增加时大腿向前=1，向后=-1；膝：命令增加时小腿相对大腿的后弯增加=1，否则=-1。
3. 用`ws`核对，静止时`save`保存。改变舵臂装配位置后应重新校准。
4. 托住机身发送`stand`，再短暂`f`检查抬脚、前迈、落地，用`stop`停止；确认无干涉后再扶持机身落地尝试。

本组已实测1路命令增加时向后摆。根据CAD中左右镜像、同侧髋/膝舵机轴向相同的安装关系，得到以下方向；用户调整后反馈方向看上去正确。其余7路没有逐路实测记录，安装朝向或舵机电气方向不同需重新确认：

|编号|关节|GPIO|按当前装配推导的dir|
|---|---|---:|---:|
|1|左前髋|4|-1|
|2|左前膝|5|1|
|3|右前髋|13|1|
|4|右前膝|14|-1|
|5|左后髋|16|-1|
|6|左后膝|17|1|
|7|右后髋|18|1|
|8|右后膝|19|-1|

这些标定值保存在各ESP32的闪存中，不在Git文件中；新板不会自动获得站姿或上述方向配置。

## 所有串口指令

115200波特率、New Line，每次一条、小写。编号1～8，角度0～180°。

|指令|功能|
|---|---|
|`f`|插值进入步态并持续前行；需站姿、8路方向及舵机attach状态完整|
|`stop`|取消步态和插值，保持最后命令姿态；不自动落脚或断电|
|`stand`|停止步态，1.5秒回已标定站姿|
|`1 90`或`set 1 90`|第1路到90°；编号和角度可替换，同时停止步态|
|`all 90`|所有舵机到90°，同时停止步态|
|`init`|所有舵机回90°，同时停止步态；不清除标定|
|`capture`|静止时记录当前八路最后命令作为站姿，不测量实际角度|
|`dir 1 -1`|设第1路方向为-1，方向只能为1或-1；停止步态|
|`save`|静止且配置完整时，保存站姿和方向到闪存|
|`load`|停止运动并读取闪存标定，不自动回站姿|
|`s`或`list`|查看接线、attach状态和最后命令角度|
|`ws`|查看行走状态、标定站姿、方向和配置完整性|
|`h`或`help`|显示帮助|

没有后退、转弯、无线控制或串口调步幅指令。单独输入`90`或`+`不被识别。修改步长/抬脚见walk_math.h，周期见walk_control.h；改变参考高度需要重新校准站姿。USB COM号会变化，GPIO16/17在此为PWM，不同时用于Serial2。

## 检查与实机状态

当前三段摆动版本已在Arduino IDE编译、烧录并完成写入校验。真实行走仍在调试：先前出现原地蠕动和右前脚拖地，本次三段时序的改善程度尚待试走确认。

scripts/test_walk_math.cpp直接检查实际固件数学头文件：40,004个腿样本验证可达性、正逆解一致、连续性、单腿摆动和支撑脚后移；另有1,001个摆动样本验证原地抬落脚、前迈时保持高度及膝弯曲。理想最大髋/膝相对参考变化约25.710°/22.695°。这些检查不验证实体干涉、承重、供电或稳定性。

```powershell
arduino-cli compile --fqbn esp32:esp32:esp32 firmware/servo_control
# 使用本机MinGW g++检查数学部分，输出放入忽略目录：
g++ -std=c++11 scripts/test_walk_math.cpp -o .cad_runtime/test_walk_math.exe
./.cad_runtime/test_walk_math.exe
```

模型假设小腿后弯、舵机命令角与几何角比例相符；不同膝分支不能仅靠dir修正。没有侧摆关节、重心迁移控制或姿态反馈，抬腿不保证三足支撑稳定。若持续嗡鸣、顶死或倾倒，停止并托住机身；拔USB不保证舵机停止，必要时切断舵机电源。当前没有通信超时自动停止。
