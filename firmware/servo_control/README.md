# 八舵机初始化与指定角度

已加入基础串口前行：`f`开始，`stop`保持，`stand`回站姿。首次必须配置站姿与方向，完整步骤见 [WALKING.md](WALKING.md)。下文原手动命令继续可用，步态扩展以WALKING.md为准。

Arduino IDE打开本目录 `servo_control.ino`，同目录保留 `servo_pins.h`。使用ESP32开发板包和ESP32Servo库。

固定接线与关节编号见 [hardware/引脚分配.md](../../hardware/引脚分配.md)。1～8路GPIO依次为4、5、13、14、16、17、18、19；按左前、右前、左后、右后，每腿先髋后膝。

## 初始化

上电自动依次初始化8路：50Hz，`attach(pin, 500, 2500)`，全部执行 `servo.write(90)`。90对应1500μs电气中位，**不是站姿，也不是机械零位都已校准**。首次运行先托起机器人或卸下腿的负载；不要让未确认的8个关节带载同时顶住。

500～2500μs沿用单舵机扩大行程的试验配置，不表示各只舵机的机械端点都已验证。程序只校验库的0～180角度输入域，避免500等数被库当成微秒，不额外设置更小的关节工作角度限位。步态方向、站姿和前行配置见WALKING.md，暂不做自动扫描或传感器控制。

## 指定角度

串口监视器115200波特率，选择New Line。每次发送一行：

```text
1 90
set 2 100
all 90
init
s
```

- `1 90`：第1路（左前髋）到90命令角度。
- `set 2 100`：第2路（左前膝）到100命令角度，和`2 100`相同。
- `all 90`：全部8路到90。
- `init`：全部回90，不重新分配PWM通道。
- `s` / `list`：显示编号、关节名、GPIO和最后命令角度；不是实测反馈。
- `h` / `help`：帮助。

单独输入`90`不被识别，因为8路控制需要知道选哪一只；请用`1 90`或`all 90`。

先逐路用85、90、95这样的小变化确认接线和转动方向，再扩大范围。平行装臂有正反两个方向，髋/膝和左右侧不一定相同。首次使用步态需按WALKING.md分别记录站姿、方向，并检查装好机构后的可达范围。

实机行走效果仍需校准和测试，不把命令角或编译结果视为传感器反馈。
