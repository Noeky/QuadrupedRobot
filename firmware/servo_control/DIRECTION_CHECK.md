# 按原CAD装配推导方向

2026-11-05对照 scripts/revise_solidworks.cs 的Assembly()及cad/current/assembly_manifest.tsv：同侧髋/膝舵机使用相同旋转矩阵，左侧为单位矩阵，右侧为绕X轴180°；前后安装朝向相同。因此，在8只舵机电气转向一致且按CAD安装的前提下，左右对应关节dir应相反。同腿髋正方向为大腿前摆，膝正方向为小腿相对大腿后弯，故同腿髋/膝dir也应相反。

CAD没有PWM命令增加与输出轴转向之间的对应，无法单凭CAD确定绝对正负。

若1路左前髋命令增加时大腿向前，候选dir按端口1..8为：

`+1 -1 -1 +1 +1 -1 -1 +1`

若1路增加时大腿向后，上述8个符号全部反转。该推导需检查实物；不要把候选值当成已测定值。膝方向看小腿相对大腿的后弯变化，不看脚尖整体运动。装配朝向或舵机电气方向不一致时需逐路确认。

当前步幅已从12mm/抬脚6mm改为28mm/12mm，但发现用户全部dir为+1，先确认方向，再上传和尝试大幅度。站姿基准保持x=0,z=65mm；仅装臂平行或全部命令90°不自动满足这个几何基准。

用户实测反馈：1路左前髋增加命令角时大腿向后摆。因此在其余舵机电气方向一致、实物按CAD安装的前提下，采用第二组候选：`-1 +1 +1 -1 -1 +1 +1 -1`。其余7路尚非逐路实测。当前站姿已通过串口save成功保存；尚未修改控制板中的dir。
