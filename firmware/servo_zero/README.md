# GPIO4 单舵机：直接输入角度

Arduino IDE打开 `servo_zero.ino`，选择实际ESP32开发板和串口。依赖已安装的ESP32Servo库。

- 扩展板1路：GPIO4 / D4。先只接这一只舵机，卸下腿部负载。
- 上电执行 `servo.write(90)`。串口监视器设115200波特率，选择New Line，输入 `90`、`85`、`95` 等整数并发送。
- 使用 `servo.attach(4, 500, 2500)`，即0～180命令映射到500～2500μs，90仍对应1500μs。旧版1000～2000μs映射下，用户观察到实际仅约90°行程，因此扩大脉宽映射进行实物验证。500～2500μs是试验配置，并非已确认的本批舵机安全端点。
- 没有额外的工作角度上限、软件脉宽窗口、缓动或自动扫描。旧版 `p`、`c`、`+`、`zero` 等命令已移除；回中位直接输入90。
- 输入角度交给ESP32Servo自身处理。正常只输入0～180；库会将负角度及小于500的超范围角度钳制，而500及以上数值在这个库中可能被当作微秒值，不是“500度”。不要以为去掉自定义限位就能获得超过机械行程的角度。
- `servo.read()` 仅回报库的命令位置，不是传感器测得的角度。是否达到真实角度和机械限位仍需实物检查；不能靠这个函数自动探限。
- 上传后首次到90命令时可能突然转动。先卸下腿的负载，按90→60→90→120确认，再逐步扩大至30/150附近。接近两端时小步试探，不直接从中位跳0或180；出现顶住、持续蜂鸣或明显卡住时停止并断舵机电源，不反复堵转。若提前出现异常，缩小attach端点并保留机械余量。

花键安装时先回90，再断舵机电源，将舵臂按关节所需方向装入；平行有正反两个方向，髋/膝及左右侧不能一律同向。供电与信号必须按板上标记连接，GPIO4不用于给舵机供电，ESP32与舵机电源共地。
