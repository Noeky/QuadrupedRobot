# 四足机器人 · SolidWorks 零件图与装配图

北京大学《先进制造与机器人实践》2026 秋季学期，第 3 组，无传感器四足机器人 PLA 机械原型。

本目录由 `cad/prototype/step/` 下的 STEP 导出件导入 SolidWorks 2026 生成：零件与装配是原生
`.SLDPRT` / `.SLDASM`，工程图是原生 `.SLDDRW`（GB 国标图框），并同时导出 PDF。

## 目录内容

| 路径 | 内容 |
|---|---|
| `parts/` | 7 个零件 `.SLDPRT`（已写入图号、名称、材料、数量、重量等自定义属性） |
| `assembly/quadruped_prototype.SLDASM` | 整机装配体（34 个零部件，含舵机与转头） |
| `assembly/components/` | 装配用零部件 `.SLDPRT`，按部位命名（`front_left_thigh` 等） |
| `drawings/` | 8 张工程图 `.SLDDRW`（7 张零件图 + 1 张装配图） |
| `drawings/pdf/` | 8 张工程图的 PDF 导出 |
| `generation_report.json` | 生成过程记录（每步的返回值、比例、视图、尺寸数量） |
| `drawing_review.json` | PDF 文字边界碰撞筛查结果（交付前自检证据） |

## 图纸说明

- 图幅：零件图为 A3（`gb_a3.drwdot` 国标图框），装配图为 A2（`gb_a2.drwdot`）。
- 投影：GB/T 第一角投影，主视图 + 俯视图（主视图下方）+ 左视图（主视图右侧）+ 等轴测图。
- 比例：见各图标题栏；等轴测图为其余视图比例的一半。主体、托盘为 1:1，大腿、小腿、压板为 2:1，
  装配图为 1:1。
- 尺寸：主视图按 SolidWorks 坐标标注方案自动标注（尺寸量自导入实体的实际几何）。
- 标题栏：图号、名称、材料、数量、设计者、日期与单件质量；比例由图纸比例自动填写。
- 技术要求：每张图左下角列出材料与打印参数、配合与装配要点、未注尺寸说明。

## 生成方式

```powershell
cd 先进制造与机器人实践\project\QuadrupedRobot
python scripts/build_solidworks.py parts assembly drawings
python scripts/build_solidworks.py verify      # 退出 SolidWorks 后重开校验更严格
python scripts/review_drawings.py              # PDF 文字边界碰撞筛查
```

脚本通过 SolidWorks COM 接口工作，`parts` / `assembly` / `drawings` / `verify` 可单独执行。
导入 STEP 时脚本会临时关闭 3D Interconnect（否则零部件只存在于临时目录、退出即失效），
生成结束后自动恢复原有设置。

## 验证与已知限制

- 重开校验：7 个零件独立打开均为 1 个实体；装配体 35 个零部件全部解析，几何无缺失。
- PDF 审查：`drawing_review.json` 记录 8 张图的文字边界碰撞数量；该审查只做风险筛查，
  不能替代人工确认尺寸链。
- **STEP 导入实体没有特征树**，图纸尺寸是"哑实体"上的自动标注，不是驱动尺寸。要改尺寸请修改
  `scripts/build_prototype.py` 后重新生成 STEP，再重跑本目录脚本。
- 大腿件自动标注较密集（33 个尺寸），个别尺寸文字相邻偏紧，建议在 SolidWorks 中手动微调
  2～3 处标注位置；其余零件图与装配图未见文字重叠。
- 装配体的零部件来自 STEP 导入，名称按部位命名（`front_left_thigh` 等），不是按图号命名。
- 电池、紧固件与线缆未建模；未做实物试装、承重、连续运动与行走验证。
